# Plant texture benchmark

Reproduces the 4-model comparison: one procedural plant, four texture materials
(fan leaf cutout; bud, stem and soil tileables), each generated by every model with pbr_gen.

```bash
python build_plant.py -- plant.glb                 # needs `pip install bpy` or run inside Blender
OPENROUTER_API_KEY=... python run_bench.py ../.. sets
python metrics.py sets viewer                       # scores + viewer-ready textures, stats.json
```

`stats.json` / `review.json` hold the results from the October 2026 run ($2.48 total).
